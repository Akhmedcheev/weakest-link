## 2. Структура и стиль меню

### Контейнер выпадающего меню
- **Фон:** чуть светлее основного (#1E1E22, #1A1D24), чтобы «приподнять» над фоном
- **Скругление:** 12–16 px (Bento)
- **Тень:** мягкая `DropShadowEffect` (BlurRadius 12–16, Opacity 0.15–0.25)
- **Рамка:** тонкая, приглушённая (#2D323E, #252A36)

### Пункт меню (MenuItem)
- **Структура:** `[Иконка] Текст [Chevron >]`
- **Отступы:** Padding 12–16 px по вертикали, 10–14 px по горизонтали
- **Hover/выбран:** фон чуть светлее (#252A36, #2A303C), скругление по контуру строки (6–8 px)
- **Chevron:** тонкий `>` справа для пунктов с подменю

### Подменю (flyout)
- Появляется **справа** от родительского пункта, на одной высоте
- Тот же стиль: тёмный фон, скругление, тень
- Компактнее основного меню

## 3. Типы меню в образцах

### A. Single-select dropdown (DocPanel)
- Выбранный пункт: **сплошной teal-фон** + белая галочка справа
- Остальные: белый текст на тёмном фоне
- Закрытое состояние: label сверху + тонкая линия + chevron вниз (underline style)

### B. Multi-select с чекбоксами (DocPanel)
- Слева — чекбокс (teal при выборе, белая галочка)
- Справа — текст
- Опция «All» может быть отдельно выделена

### C. Контекстное меню с иконками (Editor Tools)
- Слева — **цветная иконка** (красный Cut, синий Insert, жёлтый Overlay и т.д.)
- Центр — текст
- Справа — chevron `>` для подменю
- Hover: скруглённый прямоугольник, слегка светлее фон

### D. Pill-табы (DocPanel Case Details)
- **Активная вкладка:** сплошной teal, белый текст
- **Неактивная:** ghost (прозрачный фон, белый текст)
- Всё в одной pill-оболочке (segmented control)

### E. Actions dropdown (DocPanel)
- Кнопка: тёмный pill с teal-рамкой + chevron вниз
- Выпадающий список: тёмная карточка, hover = teal-фон на пункте

---

## 4. Боковая панель / фильтры (DocPanel Filters)

- **Заголовок:** «Filters» + иконка воронки + кнопка закрытия (X)
- **Поля ввода:** label сверху, поле с тонкой нижней границей или outline
- **Иконки в полях:** календарь, chevron — справа внутри поля
- **Футер:** две pill-кнопки:
  - **Cancel** — outline (прозрачный фон, teal-рамка, teal-текст)
  - **Apply** — solid teal

## 5. Идеи для нашего проекта

### Панель инструментов (☰ ИНСТРУМЕНТЫ)
- Перевести на стиль боковой панели DocPanel Filters: заголовок + закрытие, чёткие секции
- Кнопки экранов (ТРАНСЛЯЦИЯ, ЗРИТЕЛИ) — pill или ghost в зависимости от состояния

### Bento-подменю (Dashboard, Live, Analytics…)
- Пункты: иконка слева (опционально) + текст + chevron при наличии подменю
- Hover: фон #252A36, скругление 6–8 px
- Выбранный: акцентная полоска слева (как в PremiumComboBoxItem) или teal-фон

### Выпадающие списки (ComboBox)
- Уже есть **PremiumComboBoxItem** (hover + выбран с полоской)
- Можно добавить **underline style** для закрытого состояния: label + линия + chevron

### Segmented control / табы
- Для переключения режимов (например, ТАЙМЕР / ОБА в настройках трансляции) — pill-табы как в DocPanel Case Details

### ContextMenu
- Стиль Editor Tools: тёмный контейнер, скругление 12, тень
- Пункты с иконками (цвет по категории) и chevron для подменю
