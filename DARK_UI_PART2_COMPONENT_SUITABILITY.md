## 3. Критерии пригодности

### Высокая пригодность
- Прямо соответствует контексту (оператор, игровое шоу)
- Уже есть аналог в проекте или легко внедрить
- Подходит под Bento/премиальный dark
- Не требует переработки логики

### Средняя пригодность
- Полезно, но требует адаптации
- Может быть избыточно для текущего сценария
- Частично применимо

### Низкая пригодность
- Специфично для другого домена (e-commerce, соцсети)
- Визуально не подходит

### Не применимо
- Не подходит под контекст
